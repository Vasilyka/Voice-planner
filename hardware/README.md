# Компоненты Voice-planner

[Электрическая схема](Схема%20подключения%202.jpg) · [Распиновка ESP32-S3](../firmware/PINOUT.md)

| Компонент | Количество | Назначение |
| --- | ---: | --- |
| ESP32-S3-N16R8 | 1 | Запись звука, Wi-Fi и управление дисплеем |
| INMP441 | 1 | Цифровой микрофон I²S |
| GDEM035T81 | 1 | Дисплей e-paper 3,5″, 184 × 384 |
| DESPI-C02 | 1 | Адаптер дисплея с интерфейсом SPI |
| Li-Pol 3,7 В | 1 | Аккумулятор |
| TP4056 | 1 | Модуль зарядки аккумулятора |
| XL63802 | 1 | Преобразователь питания |
| USB-C | 1 | Разъём питания и подключения к компьютеру |
| Переключатель BAT / 0 / PROG | 1 | Выбор режима питания |
| Нормально разомкнутая кнопка | 1 | Управление записью |
| LED1, LED2 | 2 | Индикация записи, отправки и Wi-Fi |
| R1, R2 — 1 кОм | 2 | Ограничение тока светодиодов |
| R3, R4 — 10 кОм | 2 | Делитель напряжения аккумулятора |
| Конденсатор | 1 | Фильтрация сигнала делителя на GPIO5 |
