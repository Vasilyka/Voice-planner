# Voice-planner

Портативный голосовой планировщик на ESP32-S3. Идея проекта: записывать голосовую
команду по кнопке, передавать её на сервер и показывать задачи на e-paper-дисплее.

Сейчас сохранены отдельные прототипы записи звука и управления дисплеем.
Распознавание речи, создание задач из аудио и общий интерфейс — следующие этапы.

| Папка | Содержание |
| --- | --- |
| [tests/micro](tests/micro/README.md) | INMP441, запись WAV, отправка HTTP, сервер и проверки |
| [tests/display](tests/display/README.md) | GDEM035T81 через DESPI-C02, изображения и кнопка |
| [История проекта](docs/PROJECT_HISTORY.md) | Этапы и результаты для презентации |
| [Архитектура](docs/ARCHITECTURE.md) | Устройство системы и дальнейшие шаги |
| hardware | Материалы общей схемы |
| server | Ранее добавленные серверные материалы |

В прототипах собственные назначения GPIO. Общую схему из hardware нужно сверять
отдельно: прошивки тестов под неё не адаптированы. Скетчи загружаются по очереди.
Инструкции находятся в README каждого теста.
Пароль Wi-Fi задаётся в локальном secrets.h, исключённом из Git.
