# Voice-planner

Портативный голосовой планировщик на ESP32-S3. Идея проекта: записывать голосовую
команду по кнопке, передавать её на сервер и показывать задачи на e-paper-дисплее.

Основная прошивка записывает голос по кнопке и отправляет WAV на локальный сервер.
Сохранены также ранние самостоятельные тесты микрофона и дисплея.
Добавлена интеграция SpeechKit + YandexGPT: свободная диктовка → задачи в JSON →
таблица с кириллицей на дисплее. Для реальных запросов нужен API-ключ; интеграция
проверена пока с подменёнными ответами облака. [Настройка](server/CLOUD_SETUP.md).

Основная прошивка использует GPIO из новой схемы hardware. Дисплей подключается по
общей таблице и показывает состояния записи, обработки и таблицу дел. Старые тесты используют другие GPIO;
их нужно адаптировать перед запуском на новой сборке.
Инструкции находятся в README каждого теста.
Пароль Wi-Fi задаётся в локальном secrets.h, исключённом из Git.

Голосовое управление: удалить дело по названию/номеру, отменить последнее добавление,
отметить выполненным и восстановить удалённое. Архив сохраняется в базе, неоднозначный
запрос выводит уточнение на экран. Команды описаны в server/CLOUD_SETUP.md.
