# Voice-planner

Портативный голосовой планировщик на ESP32-S3. Удерживайте кнопку, чтобы записать команду, и отпустите для отправки. Локальный сервер распознаёт речь через Yandex SpeechKit, разбирает команду через YandexGPT и формирует таблицу дел для e-paper-дисплея.

Голосом можно добавлять, удалять, отмечать выполненными и восстанавливать дела.
