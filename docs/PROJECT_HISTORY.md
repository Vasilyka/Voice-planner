## Материал для презентации

- Задача устройства: голосовой ввод и отображение задач на e-paper.
- Узлы: микрофон, ESP32, сервер, дисплей.
- Путь аудио: I2S → PCM → WAV → HTTP → файл.
- Отдельная проверка дисплея и поиск причины отсутствия изображения.
- Автоматические проверки формата и сервера.

## Следующие проверки и задачи

- Включить OPI PSRAM и подтвердить лимит записи 30 с.
- Записать звук, отправить с ESP32 и прослушать WAV на сервере.
- Перепрошить дисплей и проверить коррекцию зеркальности и кнопку.
- Согласовать GPIO общей схемы с единой прошивкой.
- Добавить распознавание речи, создание задач и вывод списка на экран.
- Проверить питание и работу системы в корпусе.

Тесты показывают этапы разработки отдельных узлов.
Работа единого голосового планировщика пока не подтверждена.
