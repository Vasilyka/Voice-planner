# Архитектура Voice-planner

1. ESP32-S3 записывает звук с INMP441 по I²S, формирует WAV и отправляет его на `POST /voice`.
2. Сервер сохраняет запись и создаёт задание обработки. Фоновый обработчик передаёт звук в SpeechKit, а распознанный текст — в YandexGPT. Сервер проверяет структуру команд и сохраняет изменения в SQLite.
3. ESP32 получает статус через `GET /jobs/{id}` и скачивает кадр через `GET /display/frame.bin`. Сервер формирует монохромную таблицу 184 × 384 пикселя по шесть дел на страницу. ESP32 передаёт кадр на дисплей по SPI.

Сетевой опрос и обновление дисплея выполняются в отдельных задачах прошивки. Активные дела отображаются на экране, выполненные и удалённые хранятся в архиве.
