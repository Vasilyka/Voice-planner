# Локальный сервер Voice-planner

FastAPI принимает WAV. Yandex SpeechKit распознаёт речь, YandexGPT преобразует её в команды, а сервер сохраняет дела в SQLite и формирует таблицу для дисплея.

## Запуск

Заполните [настройки Yandex Cloud](CLOUD_SETUP.md). Выполните из корня репозитория в PowerShell:

```powershell
py -m pip install -r server/requirements.txt
.\server\start_server.ps1
```

Сервер слушает порт 8000. ESP32 использует локальный IP компьютера. Состояние сервера доступно по `GET /health`, записи и ошибки обработки — по `GET /jobs`, список дел — по `GET /planner.json`.

WAV и JSON отдельных записей хранятся в `server/recordings`, общий JSON — в `server/data/planner.json`, база — в `server/tasks.db`. [Пример JSON](examples/planner.example.json).

## Голосовые команды

| Команда | Действие |
| --- | --- |
| «Завтра в шесть вечера купить хлеб» | Добавить дело |
| «Удали задачу номер пять» | Удалить дело по номеру или названию |
| «Купить хлеб выполнено» | Отметить дело выполненным |
| «Отмени последнее добавление» | Удалить последнее активное дело |
| «Верни задачу номер пять» | Восстановить удалённое или выполненное дело |
| «Отмени последнее удаление» | Восстановить последнее удалённое дело |
| «Удали все дела» | Удалить все активные дела |

Выполненные и удалённые дела хранятся в архиве. При неоднозначной команде сервер выводит уточнение.
