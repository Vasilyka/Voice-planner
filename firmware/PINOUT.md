# Подключение Voice-planner

Распиновка для firmware/voice_planner/voice_planner.ino.
Она соответствует схеме hardware/Схема подключения 2.jpg и отличается от старых
самостоятельных тестов. Все номера ниже — GPIO, а не порядковые номера ножек.

## INMP441

| Контакт | ESP32-S3 |
| --- | --- |
| VDD | 3V3 |
| GND | GND |
| L/R | GND (левый канал) |
| SCK / BCLK | GPIO12 |
| WS / LRCLK | GPIO13 |
| SD | GPIO14 |

## DESPI-C02 и GDEM035T81

| Контакт DESPI | ESP32-S3 |
| --- | --- |
| BUSY | GPIO11 |
| RES / RST | GPIO10 |
| D/C | GPIO9 |
| CS | GPIO21 |
| SCK | GPIO6 |
| SDI / DIN / MOSI | GPIO8 |
| GND | GND |
| 3.3V | 3V3 |

Порядок подписей гребёнки DESPI: BUSY, RES, D/C, CS, SCK, SDI, GND, 3.3V.
Ориентироваться на подписи платы. MISO не нужен. Питание DESPI — 3,3 В.
Для SSD1685 переключатель P3 / RESE — 2.2.

Шлейф подключать при отключённом питании и открытой защёлке.
На использованной плате контакты шлейфа направлены к чёрной защёлке.
Проверить ориентацию по разъёму перед подачей питания.

В текущей прошивке CS установлен HIGH, RES удерживается LOW.
Дисплей подключён, но новые кадры не отправляются. Старое изображение e-paper
может сохраняться. Прошивать старый дисплейный тест без изменения его GPIO нельзя.

## Кнопка, индикаторы и резерв

| Элемент | Подключение | Текущее назначение |
| --- | --- | --- |
| Кнопка | GPIO4 → кнопка → GND | Удержание — запись, отпускание — отправка |
| LED1 | GPIO17 → R1 1 кОм → анод LED; катод → GND | Запись или передача HTTP |
| LED2 | GPIO16 → R2 1 кОм → анод LED; катод → GND | Горит при подключении к Wi-Fi |
| Делитель батареи | GPIO5 → средняя точка R3/R4 | Зарезервирован; измерение не реализовано |
| USB D− / D+ | GPIO19 / GPIO20 | Оставлены для USB |
| Все GND | Общая земля | Общий уровень сигналов |

Кнопка использует внутреннюю подтяжку INPUT_PULLUP, внешняя не нужна.
У четырёхножечной кнопки выбрать пару, замыкающуюся только при нажатии.
Светодиод записи гаснет при заполнении буфера и включается снова на время HTTP.

GPIO0/3/45/46 не используются как сигналы периферии из-за их роли при загрузке.
GPIO35/36/37 не используются: на платах с Octal PSRAM они заняты памятью.
GPIO19/20 сохранены для USB; GPIO43/44 — для UART0.
Назначения сверены с [документацией платы Espressif](https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s3/esp32-s3-devkitc-1/user_guide_v1.0.html)
и [даташитом ESP32-S3](https://documentation.espressif.com/esp32_s3_datasheet_en.pdf).

Файл задаёт сигнальные соединения. Работа питания от аккумулятора, переключение
BAT/PROG и обратная подпитка через преобразователь или ADC этой прошивкой не проверяются.
