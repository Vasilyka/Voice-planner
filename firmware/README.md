# Прошивка Voice-planner

[Скетч для ESP32-S3-N16R8](voice_planner/voice_planner.ino) записывает WAV по кнопке, отправляет его на сервер по Wi-Fi и выводит таблицу дел на дисплей. [Распиновка](PINOUT.md).

## Загрузка

1. В Arduino IDE установите пакет плат Espressif ESP32 и откройте скетч.
2. Скопируйте [secrets.example.h](voice_planner/secrets.example.h) в `secrets.h` рядом со скетчем. Укажите имя и пароль сети Wi-Fi 2,4 ГГц и адрес `http://IP_КОМПЬЮТЕРА:8000/voice`. ESP32 и сервер подключаются к одной локальной сети.
3. Выберите **ESP32S3 Dev Module**, **Flash Size: 16MB**, **PSRAM: OPI PSRAM** и **Partition Scheme: 16M Flash (3MB APP/9.9MB FATFS)**. Для встроенного USB выберите **Hardware CDC and JTAG** и включите **USB CDC On Boot**. При загрузке через USB-UART отключите **USB CDC On Boot**.
4. Выберите порт платы и загрузите скетч. Скорость монитора порта — 115200.

## Использование

- Удержание кнопки запускает запись, отпускание отправляет её. Формат — WAV PCM16, моно, 16 кГц. Длительность — от 0,2 до 30 с при доступной PSRAM.
- Дисплей показывает состояние и таблицу дел. Промежуточные состояния обновляются частично, итог записи — полностью. Изображение повёрнуто на 180°.
- `r` в мониторе порта повторяет отправку записи из памяти при ошибке передачи. `n` переключает страницу таблицы.
